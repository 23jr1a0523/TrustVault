## TrustVault

TrustVault is a secure, AI-powered document-sharing platform that protects documents through authentication, access control, and file integrity verification.

## Features
- User Registration and Login
- Secure Document Upload and Download
- Role-Based Access Control
- SHA-256 File Integrity Verification
- Admin Audit Logs
- AI Security Assistant

## Technologies Used
Python, Flask, SQLite, HTML, CSS, JavaScript, Google Gemini API.

## AI Tools Disclosure
- **Google Gemini API:** Powers the AI Security Assistant.
- **ChatGPT (OpenAI):** Used for coding guidance, debugging, and documentation assistance.

## Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Configure your `.env` file with your Gemini API key and secret key.
3. Run: `python run.py`
4. Open `http://127.0.0.1:5000`

**Note:** Never upload API keys, passwords, or private documents to GitHub.
