Access Control

TrustVault restricts document access to protect confidential files.

USER ROLE

Document Owner

Users can view and download only documents associated with their account. The server checks ownership before allowing a download.

ADMIN ROLE

Administrator

Administrators can view the audit logs page. Ordinary users are denied access to that page.

SECURITY

Server-side authorization

Access checks happen on the server, rather than relying only on hiding links in the website.
