File Integrity Verification

TrustVault uses SHA-256 hashing to detect unexpected changes to stored documents.

How it works

  1. When a document is uploaded, its SHA-256 hash is calculated.
  2. The hash is stored in the database with the document record.
  3. Before download, the stored file's hash is calculated again.
  4. If the hashes differ, the download is blocked.

Integrity check

Verification happens automatically.

If a file is modified after upload, TrustVault displays an integrity error instead of allowing the download.

Algorithm

SHA-256 produces a 256-bit hash value used to compare file contents.

This check detects changes when the stored reference hash remains trustworthy; it does not encrypt the document.
