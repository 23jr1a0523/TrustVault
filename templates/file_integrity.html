File Integrity Verification

Protect document integrity with SHA-256 hashing. TrustVault can detect unexpected changes by comparing a file's current hash with its stored reference hash.

Every file deserves protection.

Integrity verification helps identify document tampering and prevents downloads when a hash mismatch is detected by the backend.

🛡️
🔐

SHA-256 Hashing

Generates a fixed-length 256-bit hash based on the document's contents.

🔎

Change Detection

Comparing hashes helps detect whether file contents have changed since upload.

🚫

Download Protection

When the backend detects a mismatch, it can block the download and report an integrity error.

How verification works

  1. Upload: A document is uploaded to TrustVault.
  2. Generate hash: The backend calculates the document's SHA-256 hash.
  3. Store reference: The hash is saved with the document record.
  4. Verify: The backend recalculates the hash when checking the file.
  5. Compare: If the hashes differ, the file may have been modified.

Security details

Hash algorithm

SHA-256

SHA-256 produces a 256-bit digest, commonly represented as 64 hexadecimal characters. Even a small change to file contents normally results in a different hash.

💡

Important: Hashing is not encryption. It helps detect changes only when the stored reference hash is trustworthy and the backend actually performs the comparison.
